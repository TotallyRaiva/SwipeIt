Simple Setup

How to install and authorize SwipeIt on your Mac in 30 seconds.

1

Download & Install

Download SwipeIt.dmg, double click to open the installer disk image, and drag SwipeIt.app into your Applications folder.

2

Grant Accessibility

Open SwipeIt. macOS will prompt you to authorize Accessibility permissions in System Settings → Privacy & Security → Accessibility so SwipeIt can intercept events.

3

Lock & Clean

Click the keycap icon in your macOS menu bar or press ⌃⌥⌘L to lock. Clean your keyboard safely and press ⌃⌥⌘U when finished!

macOS Security Notice (First Launch)

"Apple cannot verify that SwipeIt is free of malware"?

Because SwipeIt is 100% free open-source software and not yet signed with a paid Apple Developer ID certificate ($99/yr), macOS Gatekeeper blocks it on first launch. This is standard for open-source Mac utilities!

Option 1: System Settings (Recommended)

Go to System Settings → Privacy & Security, scroll down to the Security section, and click "Open Anyway" (or Всё равно открыть / Подтвердить вход).

Option 2: Right-Click in Finder

In your /Applications folder, Right-click (or Control + click) on SwipeIt.app and select Open, then click Open in the dialog.

Option 3: Terminal Command

Run this command in Terminal to permanently clear the download quarantine flag:
xattr -cr /Applications/SwipeIt.app
